# Routes and Flow

Primary Routes:
- /upload — Upload Recording screen
- /processing — Processing screen (auto-advance to /dashboard)
- /dashboard — Case Dashboard with two-column layout
- /final-review — Final Review with confirmation checkbox
- /success — Submission Success screen

Flow:
Upload and Process -> Processing (auto) -> Case Dashboard -> Final Review -> Submission Success

Sidebar:
- Title: Arrangement Assistant
- Primary Navigation: all above routes
- Dashboard Tabs: shown after processing (context flag)
- Compliance section: "Compliance Checklist" link (anchors to dashboard panel)
